# Guía de Implementación de OpenAPI/Swagger en el Backend

Esta guía te ayudará a implementar OpenAPI/Swagger en tu backend de Node.js/Express para generar documentación automática de la API y permitir que el frontend genere tipos TypeScript automáticamente.

## Stack Tecnológico del Backend

- **Runtime**: Node.js con TypeScript
- **Framework**: Express
- **Documentación**: Swagger/OpenAPI 3.0+
- **Autenticación**: JWT Bearer Token

---

## Paso 1: Instalación de Dependencias

```bash
npm install swagger-jsdoc swagger-ui-express
npm install --save-dev @types/swagger-jsdoc @types/swagger-ui-express
```

## Paso 3: Configurar el Servidor Express

Actualiza tu archivo `src/app.ts` o `src/server.ts`:

```typescript
import express from 'express';
import swaggerUi from 'swagger-ui-express';
import { swaggerSpec } from './config/swagger.config';
import cors from 'cors';

const app = express();

// Middleware
app.use(express.json());
app.use(cors({
  origin: ['http://localhost:5173'], // Frontend dev server
  credentials: true,
}));

// Swagger UI
app.use('/api-docs', swaggerUi.serve, swaggerUi.setup(swaggerSpec, {
  explorer: true,
  customCss: '.swagger-ui .topbar { display: none }',
  customSiteTitle: 'Gamification Finances API Docs',
}));

// Endpoint para obtener el schema JSON (para generar tipos en frontend)
app.get('/api/schema.json', (req, res) => {
  res.setHeader('Content-Type', 'application/json');
  res.send(swaggerSpec);
});

// Tus rutas aquí
app.use('/transactions', transactionRoutes);

export default app;
```

## Paso 5: Scripts en package.json

Añade estos scripts en el `package.json` del backend:

```json
{
  "scripts": {
    "dev": "nodemon src/server.ts",
    "start": "node dist/server.js",
    "build": "tsc",
    "docs": "echo 'OpenAPI docs: http://localhost:3000/api-docs'",
    "export:schema": "curl http://localhost:3000/api/schema.json > openapi-schema.json"
  }
}
```

## Paso 7: Generar Tipos en el Frontend

Una vez que el backend esté funcionando, desde el frontend ejecuta:

```bash
# Instalar la herramienta
npm install -D openapi-typescript

# Generar tipos
npx openapi-typescript http://localhost:3000/api/schema.json -o src/types/api-generated.ts

# Agregar script en package.json
{
  "scripts": {
    "generate:types": "openapi-typescript http://localhost:3000/api/schema.json -o src/types/api-generated.ts",
    "predev": "yarn generate:types"
  }
}
```

## Notas Importantes

### Formato de Respuesta API

Todas las respuestas exitosas deben seguir este formato:

```typescript
{
  response: T,        // Los datos solicitados
  status: "ok" | "error",
  statusCode?: number,
  headers?: Record<string, string>
}
```

### Autenticación

- **Tipo**: Bearer token JWT
- **Header**: `Authorization: Bearer <token>`
- La documentación incluye un botón "Authorize" para probar con token

### CORS

Configurar CORS para permitir peticiones desde:
- `http://localhost:5173` (frontend dev)
- Tu dominio de producción

### Validaciones

Documenta las validaciones esperadas:
- Campos obligatorios
- Formatos (ISO 8601 para fechas)
- Rangos numéricos (amount > 0)
- Enums (type, category)
